# BRASA 政府服務

**依照公民實際使用的機構和服務整理政府資訊。**

[開啟 BRASA 政府服務](https://brasagovernment.net/) · [BRASA 世界](https://brasa.world/) · [教育](https://brasa.education/) · [商業](https://brasa.business/)

BRASA 政府服務為每個國家提供結構一致的公共服務網站，同時保留該國真實的政府體系。頁面將公民連結到各部會、部門、公用事業機構、公共機構和官方監測資源。

## 每個國家網站包含的內容

- 行政、立法、司法及其他憲法機構
- 部會、部門、機構和公共實體
- 電力、供水、燃料、通訊、網際網路、廢棄物處理和衛生服務提供者
- 教育、交通、衛生、勞動、商業、身分及其他公民服務
- 官方來源和核實日期

## 各國資訊準確性

各國的政府結構並不相同。BRASA 使用共同的視覺框架，但機構和頁面數量依據該國經核實的資料決定，而不是從其他國家複製。

## 語言存取

英文結構保持可編輯。部會和機構名稱可以保留其官方在地語言形式，在地化公共頁面則擁有獨立網址和審查記錄。

## 尋找您所在國家的政府服務

從 [BRASA 世界](https://brasa.world/) 開始，進入您所在國家的政府網站。

## 參與貢獻

回報過期的官方連結、提供政府來源，或協助審查某個國家的公共服務資訊。
