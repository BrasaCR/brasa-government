# BRASA 政府服务

**围绕公民实际使用的机构和服务组织政府信息。**

[打开 BRASA 政府服务](https://brasagovernment.net/) · [BRASA 世界](https://brasa.world/) · [教育](https://brasa.education/) · [商业](https://brasa.business/)

BRASA 政府服务为每个国家提供结构一致的公共服务网站，同时保留该国真实的政府体系。页面将公民连接到各部委、部门、公用事业机构、公共机构和官方监测资源。

## 每个国家网站包含的内容

- 行政、立法、司法及其他宪法机构
- 部委、部门、机构和公共实体
- 电力、供水、燃料、通信、互联网、废物处理和卫生服务提供者
- 教育、交通、卫生、劳动、商业、身份及其他公民服务
- 官方来源和核实日期

## 各国信息准确性

各国的政府结构并不相同。BRASA 使用共同的视觉框架，但机构和页面数量依据该国经核实的数据确定，而不是从其他国家复制。

## 语言访问

英文结构保持可编辑。部委和机构名称可以保留其官方本地语言形式，本地化公共页面则拥有独立地址和审核记录。

## 查找您所在国家的政府服务

从 [BRASA 世界](https://brasa.world/) 开始，进入您所在国家的政府网站。

## 参与贡献

报告过期的官方链接、提供政府来源，或协助审核某个国家的公共服务信息。
