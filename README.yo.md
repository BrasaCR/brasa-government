# Ìjọba Brasa

**Ìsọfúnniìjọba tí a ṣètò káàkiri àwọn ilé-iṣẹ́ àti àwọn iṣẹ́ tí àwọn ọmọ ìlú ń lò.**

[Ṣí ìjọba Brasa](https://brasagovernment.net/)·[BRASA World](https://brasa.world/)·[Ẹ̀kọ́](https://brasa.education/)·[Okòwò](https://brasa.business/)

Ìjọba BRASA fún olúkúlùkù orílẹ̀-èdè ní ojú òpó ayélujára iṣẹ́ ìjọba tí ó dúró ṣánṣán nígbà tí ó ń pa ètò gidi orílẹ̀-èdè náà mọ́. Àwọn ojúewé máa ń so àwọn ọmọ ìlú pọ̀ mọ́ àwọn ẹ̀ka ìjọba, àwọn ẹ̀ka, àwọn ohun èlò, àwọn ilé-iṣẹ́ ìjọba, àti àwọn ohun-èlò ìṣàyẹ̀wò.

## Ohun tí ibùdó orílẹ̀ èdè kọ̀ọ̀kan ní

- Olùdarí, aṣòfin, ẹjọ́, àti àwọn ilé-ìgbìmọ̀ òfin mìíràn
- Àwọn ẹ̀ka ọ́fíìsì, àwọn ẹ̀ka, àwọn ilé iṣẹ́, àti àwọn ẹ̀ka ìjọba
- Ina, omi, epo, awọn ibaraẹnisọrọ, intanẹẹti, egbin, ati awọn olupese imototo
- Ẹ̀kọ́, ìrìn-àjò, ìlera, iṣẹ́, òwò, ìmísí, àti àwọn iṣẹ́ ọmọ ìlú mìíràn
- Awọn orisun osise ati awọn ọjọ ijẹrisi

## Àsọtẹ́lẹ̀ orílẹ̀-èdè

Kì í ṣe gbogbo orílẹ̀-èdè ló ní ètò ìjọba kan náà. BRASA máa ń lo àtòjọ àwòrán tí a pín, ṣùgbọ́n àwọn ilé-iṣẹ́ àti iye ojú-ìwé ni a máa ń pinnu nípa àwọn àkóónú orílẹ̀-èdè tí a ti fìdí múlẹ̀ dípò tí a ó fi máa ṣe àdàkọ láti orílẹ̀ èdè mìíràn.

## Èdè ìfikúnsí

Èdè Gẹ̀ẹ́sì náà ṣì lè ṣe àtúnṣe. Àwọn orúkọ ilé-iṣẹ́ àti ilé-iṣẹ́ lè pa fọ́mù èdè ìbílẹ̀ wọn mọ́, nígbà tí àwọn ojú-ìwé gbogbo ènìyàn tó wà ní àdúgbò ń gba àwọn URL tí ó yàtọ̀ àti àwọn àkọsílẹ̀ àtúnyẹ̀wò.

## Wá ìjọba rẹ

Bẹrẹ ni[BRASA World](https://brasa.world/)láti dé ibi ìjọba fún orílẹ̀-èdè rẹ.

## Ilowosi

Sọ ìjápọ́ ìjọba tí ó ti di ìgbà pípẹ́, pèsè orísun ìjọba, tàbí ṣe ìrànlọ́wọ́ láti ṣe àtúnyẹ̀wò àlàyé iṣẹ́ ìjọba orílẹ̀-èdè kan.

## BRASA lónìí

BRASA ti so àwọn ibi orílẹ̀-èdè 198 pọ̀ mọ́ Ẹ̀kọ́, Ìjọba àti Iṣòwò. BRASA Business ní apá 12 tí ó so pọ̀: títà àti risiti, CRM, ọjà inú ilé, ènìyàn àti ìdánilẹ́kọ̀ọ́, owó oṣù àti ilé-ifowopamọ́, àkókò, ìrànlọ́wọ́ ẹbí, iṣẹ́ òfin, fọ́ọ̀mù ìjọba, ìròyìn àti ibi iṣẹ́ àjọṣe. Ó tún ní ìwé ìṣirò ṣíṣi, ìlànà iṣẹ́ tí a darí àti ìtẹ̀síwájú láìsí íńtánẹ́ẹ̀tì.

BRASA Financials ṣe àkójọ àwọn ètò ìsanwó 385 láti inú àkọsílẹ̀ 395, pẹ̀lú àlàyé ọjà 161 àti irú ìsanwó 216: owó alágbèéká, gbigbe lẹ́sẹ̀kẹsẹ̀, QR, àpò owó díjítà, nẹ́tíwọ́ọ̀kì owó, fífi owó ránṣẹ́, open banking, káàdì abẹ́lé àti USSD.

Wíwà nínú àkójọ kò túmọ̀ sí pé a ti mú un ṣiṣẹ́. Àwọn olupèsè tó ní ìwé-àṣẹ ni wọ́n ń gbé owó; ọ̀nà kọ̀ọ̀kan nílò àyẹ̀wò orílẹ̀-èdè àti orísun, ìwé-àṣẹ, ìsopọ̀, ìdánwò ìsanpada àti ìfọwọ́sí iṣẹ́ gidi.
