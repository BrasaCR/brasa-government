# BRASA 行政サービス

**市民が実際に利用する機関とサービスを中心に、政府情報を整理します。**

[BRASA 行政サービスを開く](https://brasagovernment.net/) · [BRASA 世界](https://brasa.world/) · [教育](https://brasa.education/) · [ビジネス](https://brasa.business/)

BRASA 行政サービスは、各国の実際の制度を保ちながら、一貫した公共サービスサイトを提供します。ページは市民を省庁、部局、公共サービス事業者、公共機関、公式監視資源につなぎます。

## 各国サイトの内容

- 行政、立法、司法、その他の憲法上の機関
- 省庁、部局、庁、公共団体
- 電気、水道、燃料、通信、インターネット、廃棄物、衛生の事業者
- 教育、交通、健康、労働、事業、本人確認、その他の市民サービス
- 公式情報源と確認日

## 国ごとの正確性

政府の仕組みは国によって異なります。BRASA は共通の視覚構成を使いますが、機関とページ数は各国の確認済みデータで決まり、他国から複製されません。

## 言語での利用

英語の構成は編集可能なままです。省庁や機関の名称は公式の現地語表記を維持でき、ローカライズされた公共ページには個別のアドレスと確認記録が付きます。

## 自国の行政サービスを探す

[BRASA 世界](https://brasa.world/) から、自国の政府サイトへ進んでください。

## 協力する

古い公式リンクの報告、政府情報源の提供、各国の公共サービス情報のレビューにご協力ください。

## 現在のBRASA

BRASAは現在、198の国別ページを教育・政府・ビジネスと結び付けています。BRASA Businessには、販売時点管理と領収書、CRM、在庫、人材と研修、給与と銀行、時間管理、家族支援、法務、政府書式、レポート、共有ワークスペースという12の連携領域があります。オープン台帳、ガイド付きワークフロー、オフライン継続運用も含まれます。

BRASA Financialsは395件の記録から385の決済システムを整理し、161の国・複数国市場の説明と216の決済種類を収録しています。モバイルマネー、即時振込、QR、ウォレット、現金ネットワーク、送金、オープンバンキング、国内カード、USSDなどが含まれます。

掲載は利用開始や承認を意味しません。資金を移動するのは認可を受けた事業者です。各方式には、国と公式情報源の確認、認可、接続、決済テスト、本番承認が必要です。BRASAは確認済みの選択肢を領収書、照合、オープン台帳につなぎます。
