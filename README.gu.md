# BRASA સરકાર

**સંસ્થાઓ અને સેવાઓની આસપાસ આયોજિત સરકારી માહિતી જે નાગરિકો વાસ્તવમાં ઉપયોગ કરે છે.**

[BRASA સરકાર ખોલો](https://brasagovernment.net/) · [બ્રાસા વર્લ્ડ](https://brasa.world/) · [શિક્ષણ](https://brasa.education/) · [વ્યાપાર](https://brasa.business/)

BRASA સરકાર દેશની વાસ્તવિક રચનાને સાચવીને દરેક દેશને એક સુસંગત જાહેર-સેવા વેબસાઇટ આપે છે. પૃષ્ઠો નાગરિકોને સત્તાવાર મંત્રાલયો, વિભાગો, ઉપયોગિતાઓ, જાહેર સંસ્થાઓ અને મોનિટરિંગ સંસાધનો સાથે જોડે છે.

## દરેક દેશની સાઇટમાં શું છે

- કારોબારી, કાયદાકીય, ન્યાયિક અને અન્ય બંધારણીય સંસ્થાઓ
- મંત્રાલયો, વિભાગો, એજન્સીઓ અને જાહેર સંસ્થાઓ
- વીજળી, પાણી, ઇંધણ, સંચાર, ઇન્ટરનેટ, કચરો અને સ્વચ્છતા પ્રદાતાઓ
- શિક્ષણ, પરિવહન, આરોગ્ય, શ્રમ, વ્યવસાય, ઓળખ અને અન્ય નાગરિક સેવાઓ
- સત્તાવાર સ્ત્રોતો અને ચકાસણી તારીખો

## દેશની ચોકસાઈ

બધા દેશોમાં સમાન સરકારી માળખું નથી. BRASA શેર કરેલ વિઝ્યુઅલ ફ્રેમવર્કનો ઉપયોગ કરે છે, પરંતુ સંસ્થાઓ અને પૃષ્ઠ સંખ્યા અન્ય રાષ્ટ્રમાંથી નકલ કરવાને બદલે ચકાસાયેલ દેશના ડેટા દ્વારા નક્કી કરવામાં આવે છે.

## ભાષા ઍક્સેસ

અંગ્રેજી માળખું સંપાદનયોગ્ય રહે છે. મંત્રાલય અને સંસ્થાના નામો તેમના સત્તાવાર સ્થાનિક-ભાષાના સ્વરૂપને જાળવી શકે છે, જ્યારે સ્થાનિક જાહેર પૃષ્ઠો અલગ URL અને સમીક્ષા રેકોર્ડ મેળવે છે.

## તમારી સરકાર શોધો

તમારા દેશની સરકારી સાઇટ પર પહોંચવા માટે [બ્રાસા વર્લ્ડ](https://brasa.world/) થી પ્રારંભ કરો.

## ફાળો આપો

જૂની સત્તાવાર લિંકની જાણ કરો, સરકારી સ્ત્રોત પ્રદાન કરો અથવા દેશની જાહેર-સેવા માહિતીની સમીક્ષા કરવામાં સહાય કરો.

## BRASA આજે

BRASA હવે 198 દેશના સ્થળોને શિક્ષણ, સરકાર અને વ્યવસાય સાથે જોડે છે. BRASA Businessમાં 12 જોડાયેલા ક્ષેત્રો છે: વેચાણ અને રસીદો, CRM, માલસામાન, લોકો અને તાલીમ, પગાર અને બેન્કિંગ, સમય, પરિવાર સહાય, કાનૂની કામ, સરકારી ફોર્મ, અહેવાલો અને સહિયારું કાર્યસ્થળ. તેમાં ખુલ્લું લેજર, માર્ગદર્શિત કાર્યપ્રવાહ અને ઑફલાઇન સતત કામગીરી સામેલ છે.

BRASA Financials 395 રેકોર્ડમાંથી 385 ચુકવણી પ્રણાલીઓની સૂચિ આપે છે, જેમાં 161 બજાર વર્ણનો અને 216 ચુકવણી પ્રકારો છે: મોબાઇલ મની, તાત્કાલિક ટ્રાન્સફર, QR, વૉલેટ, રોકડ નેટવર્ક, રેમિટન્સ, ઓપન બેન્કિંગ, સ્થાનિક કાર્ડ પ્રણાલીઓ અને USSD.

સૂચિમાં હોવું એટલે સક્રિય હોવું નહીં. લાઇસન્સ ધરાવતા પ્રદાતાઓ નાણાં ખસેડે છે; દરેક પદ્ધતિ માટે દેશ અને સ્રોતની સમીક્ષા, લાઇસન્સ, એકીકરણ, સેટલમેન્ટ પરીક્ષણ અને ઉત્પાદન મંજૂરી જરૂરી છે. BRASA ચકાસાયેલ વિકલ્પોને રસીદો, સમાધાન અને ખુલ્લા લેજર સાથે જોડે છે.
