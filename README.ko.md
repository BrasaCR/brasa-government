# BRASA 정부 서비스

**시민이 실제로 이용하는 기관과 서비스를 중심으로 정부 정보를 정리합니다.**

[BRASA 정부 서비스 열기](https://brasagovernment.net/) · [BRASA 세계](https://brasa.world/) · [교육](https://brasa.education/) · [비즈니스](https://brasa.business/)

BRASA 정부 서비스는 각 국가의 실제 구조를 보존하면서 일관된 공공서비스 사이트를 제공합니다. 페이지는 시민을 부처, 부서, 공공서비스 제공자, 공공 기관, 공식 모니터링 자원과 연결합니다.

## 각 국가 사이트의 내용

- 행정부, 입법부, 사법부 및 기타 헌법 기관
- 부처, 부서, 기관 및 공공 단체
- 전기, 수도, 연료, 통신, 인터넷, 폐기물, 위생 서비스 제공자
- 교육, 교통, 보건, 노동, 사업, 신원 및 기타 시민 서비스
- 공식 출처와 확인 날짜

## 국가별 정확성

모든 국가의 정부 구조가 같지는 않습니다. BRASA는 공통 시각 틀을 사용하지만, 기관과 페이지 수는 다른 국가에서 복사하지 않고 해당 국가의 검증된 자료로 결정합니다.

## 언어 접근

영어 구조는 계속 편집할 수 있습니다. 부처와 기관 이름은 공식 현지어 형태를 유지할 수 있고, 현지화된 공공 페이지에는 별도 주소와 검토 기록이 제공됩니다.

## 자국의 정부 서비스 찾기

[BRASA 세계](https://brasa.world/)에서 시작하여 자국 정부 사이트로 이동하세요.

## 참여하기

오래된 공식 링크를 신고하고, 정부 출처를 제공하거나, 국가의 공공서비스 정보 검토를 도와주세요.

## 오늘의 BRASA

BRASA는 이제 198개 국가 목적지를 교육, 정부, 비즈니스와 연결합니다. BRASA Business에는 판매와 영수증, CRM, 재고, 인사와 교육, 급여와 금융, 시간 관리, 가족 지원, 법무, 정부 양식, 보고서, 공동 작업 공간 등 12개의 연결된 운영 영역이 있습니다. 오픈 원장, 안내형 업무 흐름, 오프라인 연속 운영도 포함됩니다.

BRASA Financials는 395개 기록에서 385개 결제 시스템을 정리했으며, 161개 국가 또는 다국가 시장 설명과 216개 결제 유형을 포함합니다. 모바일 머니, 즉시 이체, QR, 지갑, 현금 네트워크, 송금, 오픈뱅킹, 국내 카드 시스템, USSD 등이 포함됩니다.

목록에 있다는 것은 활성화되었다는 뜻이 아닙니다. 자금은 인가된 제공업체가 이동하며, 각 방식은 국가와 공식 출처 검토, 인허가, 연동, 정산 시험, 운영 승인을 거쳐야 합니다. BRASA는 검증된 선택지를 영수증, 대사, 오픈 원장에 연결합니다.
